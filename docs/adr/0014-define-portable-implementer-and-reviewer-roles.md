# Define portable Implementer and Reviewer roles

Exspecso owns portable Execution Role contracts for implementation and review and ships a default review workflow. Final Review consumes a bounded Review Packet that excludes the Implementer's scratch reasoning and self-assessment. A runtime with isolated agent support may map the Reviewer contract to a bundled native reviewer agent; otherwise `/exspecso-review` must execute in a fresh agent context. Compatible user-defined agents may replace default implementations while remaining subject to the same contract. The implementation context cannot issue its own passing review, and the shared CLI validates review inputs, provenance, fingerprints, Git state, and report schema. Runtime-specific prompts and named agents remain thin, replaceable adapters rather than canonical workflow authority.
