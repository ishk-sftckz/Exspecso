# Execute only bounded approved verification commands

Verification commands are structured, fingerprinted capabilities declared in an approved Evidence Contract before implementation. They specify executable, argument array, working directory, timeout, expected exit behavior, permitted environment-variable names, and declared write or external capabilities. Direct argument execution is the default; shell evaluation, network or external services, privilege, and destructive access require explicit risk declarations and human confirmation. Secret values are never recorded, output is bounded with overflow retained as referenced evidence, and unexpected tracked-file changes block acceptance. Repository content and process output are untrusted data rather than instructions. Evidence records the command fingerprint, result, duration, relevant output, file effects, and Git state. Correction may rerun approved commands but cannot invent expanded execution authority; new commands require approved planning change or explicit human authorization.
