# Return versioned typed Operation Results

Every CLI operation returns a versioned Operation Result containing its operation and target IDs, typed outcome, before-and-after fingerprints and Git state, changed artifacts, evidence or blocker references, warnings, and one recommended next command. Outcomes include `completed`, `paused`, `no-change`, `blocked`, `review-required`, `needs-human`, `correction-exhausted`, `interrupted`, `invalid`, `unsupported`, and `internal-error`. Exit code `0` represents intended successful boundaries; `2` valid workflow stops requiring action; `3` invalid input, configuration, artifacts, or readiness; `4` missing runtime or environment capability; `5` invariant or internal failure; and `130` user interruption. Human-readable output is default and `--json` emits the same undecorated envelope. Adapters consume typed results rather than parsing prose, while only relevant canonical transitions and the projected latest result are persisted without an operation database.
