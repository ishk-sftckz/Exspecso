# Separate brownfield installation from baseline declaration

`npx exspecso init` installs project configuration, schemas, the pinned Tool Runtime, and selected Runtime Adapters without inferring Requirements, creating evidence, or marking existing work done. `/exspecso-start` may inspect repository content and existing documents to propose orientation, a Roadmap, and explicit baseline Phases, all requiring human confirmation. Baselines record historical capability and relevant fingerprints but carry no Exspecso Verified Checkpoints. Existing documents remain reference inputs until promoted through Content-bound Approval, and changes to baseline capabilities become active delivery work. Initialization does not silently migrate legacy formats, replace runtime configuration, commit user changes, or require a clean repository when generated paths are conflict-free; Task activation still requires a clean Task Baseline.
