# Own trace links in source artifacts

Canonical traceability relationships live with their source artifacts: Specifications own Requirement-to-Acceptance-Criterion-to-Verification-Intent links; Plans and Tasks own coverage, dependency, and Evidence Contract links; Verified Checkpoints own accepted evidence links; Closure Reports own cross-Task closure coverage; and Final Review findings reference the smallest applicable stable IDs. The CLI constructs a trace graph from these sources and checks in a deterministic `trace.md` projection for review. Delivery and review compute from source links rather than trusting that projection. Missing, dangling, duplicated, or contradictory links fail Readiness Validation, while stale `trace.md` is reported by read-only status and regenerated by the next authorized mutation.
