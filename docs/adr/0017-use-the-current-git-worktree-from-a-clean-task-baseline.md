# Use the current Git worktree from a clean Task baseline

V1 executes the Delivery Loop in the user's current Git working tree and does not create a branch or Git worktree for each Task. Task activation requires a clean tracked index and working tree against a recorded base commit; non-ignored untracked files must be surfaced and explicitly classified, while ignored files may remain. Exspecso records the Task Baseline and approved path scope, stages explicit verified paths rather than using broad staging, and never commits, stashes, discards, or rewrites pre-existing user changes. Unexpected or unowned changes block checkpoint acceptance and require Evidence Boundary impact classification. A Verified Checkpoint commit contains only the Task's verified implementation and required artifact transitions. Isolated worktrees may be offered later as an explicit strategy rather than V1's default.
