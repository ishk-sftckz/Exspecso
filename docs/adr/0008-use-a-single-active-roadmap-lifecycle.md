# Use a single active Roadmap lifecycle

Roadmaps use `active`, `blocked`, `done`, `superseded`, and `cancelled` states, with the `activeRoadmap` configuration field pointing to at most one current nonterminal Roadmap. That pointer remains stable when its Roadmap moves from `active` to `blocked`; it is an orientation selection rather than a duplicate lifecycle status. `done` requires every retained delivery Phase to be done while explicit baseline Phases count only as satisfied historical context; `blocked` means unfinished required work has no progressable Phase. Creating a new Roadmap must explicitly leave the previous one `done`, `superseded`, or `cancelled`, and cancelled Phase scope is excluded only through a recorded Roadmap revision rather than silent roll-up behavior.
