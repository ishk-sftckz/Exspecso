# Require runtime semantic conformance with graceful degradation

Every supported runtime must read and write repository artifacts, execute the pinned local Exspecso CLI and approved verification commands, inspect Git and create explicitly scoped commits, present human confirmation boundaries, and reconstruct canonical state from a cold start. Initialization and operations probe these required capabilities and stop with a typed unsupported-capability result when one is absent. Native subagents, custom agent definitions, hooks, MCP, background execution, and rich prompts are optional enhancements with documented fallbacks, such as fresh-session review. Claude Code, Codex CLI/IDE/Desktop, and OpenCode adapters must produce identical canonical transitions and typed results under a shared conformance suite; optional host features cannot alter correctness semantics.
