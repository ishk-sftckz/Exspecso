# Use versioned artifact schemas and deterministic Markdown

Canonical artifacts use versioned YAML frontmatter for validated structure and Markdown sections for reviewable meaning. Required frontmatter includes `schemaVersion`, stable identity, revision, lifecycle state, parent relationships, and links needed for deterministic computation. The CLI owns lifecycle fields, fingerprints, checkpoint references, generated timestamps, Status Summaries, and Trace Summaries; humans and agents author the defined semantic Markdown sections. Unknown fields are preserved with warnings unless forbidden, while missing, malformed, or contradictory required structure blocks mutation rather than triggering guessed repairs. Deterministic serialization keeps Git diffs readable. Schema migrations are explicit, versioned, reversible where possible, and committed separately from product delivery checkpoints.
