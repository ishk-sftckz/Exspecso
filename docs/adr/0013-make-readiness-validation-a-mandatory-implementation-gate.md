# Make readiness validation a mandatory implementation gate

`/exspecso-verify` is an optional explicit preflight operation, but the same deterministic Readiness Validation is mandatory whenever implementation begins or resumes. It checks approval and revision consistency, traceability, Acceptance Criteria, Verification Intent, Evidence Contracts, dependencies, and required capabilities. Its fingerprint-bound `verify-report.md` records `pass`, `warn`, or `fail`: failure blocks readiness, warnings are non-blocking unless policy makes their class blocking, and passing proves planning readiness rather than product correctness. Relevant artifact changes make the report stale, and `/exspecso-implement` always recomputes readiness from canonical artifacts rather than trusting an earlier result.
