# Install owned repository-local runtime adapters

`npx exspecso init` generates thin repository-local adapters with the same canonical hyphenated operation names and semantics. Codex CLI, IDE, and Desktop use `.agents/skills/exspecso-*`; Claude Code uses `.claude/skills/exspecso-*`; and OpenCode receives `.opencode/commands/exspecso-*.md` for reliable explicit slash invocation while also being able to discover the shared Agent Skills. All wrappers delegate behavior to the shared CLI. An Adapter Manifest records each generated path, runtime, template version, and content hash. Reinitialization updates only unchanged managed files, edited files require explicit conflict resolution, and uninstall removes only files whose hashes still match. Hooks, MCP servers, plugins, and wholesale runtime configuration changes are excluded from the default installation.
