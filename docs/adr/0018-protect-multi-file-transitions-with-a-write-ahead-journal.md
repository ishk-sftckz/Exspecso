# Protect multi-file transitions with a write-ahead journal

Exspecso computes and validates an entire artifact transition before writing, then records target paths, original and intended hashes, and the Task Baseline in a disposable gitignored write-ahead journal. Files are replaced atomically at file level, while the Git checkpoint commit remains the final durable acceptance boundary. A write or commit failure prevents Task completion, preserves implementation and provisional evidence, moves the Task to `blocked`, and records a Resume Checkpoint. Every later Exspecso operation first detects unfinished transactions and may roll forward or restore only content whose hashes still match the journal; external edits require human reconciliation. The journal is deleted only after the Verified Checkpoint and canonical artifact changes are committed, and it never serves as canonical project state.
