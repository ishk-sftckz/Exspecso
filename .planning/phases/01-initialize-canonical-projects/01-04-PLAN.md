## Trust Boundaries

| Boundary | Description |
|---|---|
| User-edited canonical files → parser/validator | Repository JSON and Markdown are untrusted input that may be malformed or relationally inconsistent. |
| Stable ID → canonical file/section | An identifier can match zero, one, or multiple definitions and must never resolve ambiguously. |
| Validator result → init mutation | Only a fully valid current artifact set may cross into mutation planning. |
