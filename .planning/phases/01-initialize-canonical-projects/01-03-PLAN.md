<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime detection → terminal presentation | Environment evidence is untrusted metadata and cannot authorize installation. |
| User selection → adapter mutation plan | Explicit submitted intent determines durable generated-file targets. |
| Adapter registry → runtime-native discovery paths | Constant repository-relative paths cross into host-consumed files. |

## STRIDE Threat Register (ASVS Level 1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Elevation of privilege | runtime detection | high | mitigate | Make detection a label-only value; selection tests assert every option starts unchecked and persisted agents equal submitted agents. |
| T-03-02 | Tampering | adapter destination | high | mitigate | Use a closed constant registry of repository-relative destinations and the existing Git-root containment boundary. |
| T-03-03 | Tampering | selected adapter set | medium | mitigate | Pure plan construction consumes an immutable selected set and power-set tests assert no extra target. |
| T-03-04 | Spoofing | native invocation | medium | mitigate | Fixture-test each official native path/sigil against `docs/research/runtime-command-naming.md`; preserve one literal operation ID. |
| T-03-05 | Repudiation | interactive cancellation | low | accept | Cancellation produces a typed result and zero-write test evidence; no durable audit log is warranted for a local pre-init action. |
</threat_model>
