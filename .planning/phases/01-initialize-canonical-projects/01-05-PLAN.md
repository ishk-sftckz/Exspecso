## Trust Boundaries

| Boundary | Description |
|---|---|
| Existing adapter bytes → ownership classifier | User-controlled content claims or lacks Exspecso ownership metadata. |
| Conflict diff → replacement approval | A human-reviewed prior conflict can authorize replacement only while its preimage remains current. |
| Init plan → transaction | The full selected change set must be conflict-free before any durable write begins. |

## STRIDE Threat Register (ASVS Level 1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Tampering | locally modified/unowned adapter | high | mitigate | Require valid managed header plus matching body hash; preserve and diff every mismatch, with explicit replacement and preimage recheck. |
| T-05-02 | Elevation of privilege | unchecked/detected adapter | high | mitigate | D-10 tests prove omission/detection never grants delete, refresh, or replacement authority. |
| T-05-03 | Tampering | partial selected change set | high | mitigate | D-12 immutable complete-plan preflight aggregates every conflict and blocks all staging when one remains. |
| T-05-04 | Spoofing | forged managed header | medium | mitigate | Header parser requires exact version/hash syntax and compares SHA-256 against actual body; a forged matching header grants ownership only of that explicit file, not arbitrary paths. |
| T-05-05 | Repudiation | explicit replacement | low | accept | Command arguments, emitted diff, and verified Task commit provide sufficient local evidence; no hidden approval log is introduced. |
</threat_model>
